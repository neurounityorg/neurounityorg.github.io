# Build notes

This repository contains the public Neurounity website.

The Neurounity student team chose the project focus and goals, set the visual
direction, and reviewed the site's content. AI coding tools helped with parts of
the implementation, debugging, and revision. The team is responsible for
checking the science, wording, privacy claims, and behavior before sharing the
site with schools.

GitHub's contributor list records commit authors. It does not list every tool
used during development.
