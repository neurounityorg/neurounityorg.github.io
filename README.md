# Neurounity Initiative

Neurounity is a student-run neuroscience project in Syosset, New York. We are
developing a school workshop about stress, attention, and reaction time using
physics, math, coding, and medicine.

The workshop is still in development. This website includes the current
reaction-time task so students and teachers can try it before the first pilot.

## Run locally

From this directory:

```sh
python3 -m http.server 8000
```

Then open <http://localhost:8000>.

## Files

- `index.html`: page structure and copy
- `styles.css`: layout, responsive design, and visual system
- `app.js`: navigation, reaction-time task, and lightweight visual effects
- `assets/`: logo, favicon, and social preview
- `.github/workflows/deploy.yml`: GitHub Pages deployment

The task keeps results only in the open browser tab. This project has no account
system, analytics, or cookies.

The student team set the project's direction and reviewed its content. AI coding
tools assisted with parts of the implementation and debugging.
